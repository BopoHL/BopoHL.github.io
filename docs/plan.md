# Дело № 404 — план сайта-визитки

Нуар-сайт разработчика Леонида Воронина. Вместо резюме — доска следователя: пробковая доска под тёплой лампой, газетные вырезки, напечатанные на машинке досье, стикеры с вопросами и цветные нити между уликами. Скролл ведёт камеру по доске, расследование заканчивается раскрытием личности и контактами.

**Цель:** найти работу backend PHP/Laravel (удалёнка + СНГ).
**Зрители:** HR (30 секунд, часто с телефона) и техлиды (готовы залипнуть). Поэтому кнопка «Пропустить расследование → досье» доступна всегда, а PDF-резюме скачивается в один клик.

## 1. Подход

Гибрид, где основа — realtime 3D в браузере:

| Слой | Чем делаем | Зачем |
|---|---|---|
| Сцена | Next.js + React Three Fiber, WebGL | Живой текст (RU/EN, SEO), фонарик, интерактив, работает на телефоне |
| Тексты на карточках | Рисуются кодом в canvas-текстуры | Любой шрифт с кириллицей, «неровная» печать машинки, переключение языка без перерендера |
| Фото и газетные иллюстрации | Твои фото + картинки из GPT | Пайплайн сам приводит любое фото к нуар-грейду (десатурация, зерно, тёплый свет) |
| Превиз и эталон картинки | Blender, сцена собирается скриптом из тех же данных | Сравнить «кинорендер» с realtime, позже — запечь свет и текстуры |
| Seedance | Опционально, в самом конце | Только для киношного интро или фона прелоадера, не для основы |

## 3. Маршрут камеры

| # | Остановка | Субтитр RU | Субтитр EN |
|---|---|---|---|

Нити «прорисовываются» по мере расследования: связь появляется, когда камера доходит до улики. На общем плане видна вся паутина.

## 4. Улики

Полные тексты на двух языках лежат в `src/content/board.ts`. Это единственный источник: из него строятся и сайт, и сцена в Blender. Все факты взяты из CV.

- **Центр:** фото-силуэт на фоне ростовой линейки, ярлык «ДЕЛО № 404 — ЛИЧНОСТЬ НЕ НАЙДЕНА», стикер «Кто этот таинственный разработчик?», бирка «Особые приметы» со стеком, перехват «Говорит: RU, EN (C1), учит ES».
- **Alif:** вырезка «Задержка API упала в 5 раз» (1000 → ~200 мс); график на миллиметровке; досье (Unified Identity, MyID, DDD/CQRS, скоринг для compliance, загрузка по QR, схема интеграции партнёров); заметка «Счета за облако похудели»; слух «Двое джунов утверждают, что он был их наставником».
- **DMed:** вырезка про интеграции с МВД и прокуратурой; секретный документ с вымаранными строками (подрядчик скрыт); заметка про SeaweedFS; стикер «Процессы улучшились за несколько месяцев. Кто ещё был способен на такое?».
- **Проекты:** Split the Bill (Telegram Mini App, ссылка на бота), GitHub, «Этот сайт — тоже улика», пустой слот «Дело № 2 — засекречено».
- **Учёба:** студенческий билет ITPU, вырезка про стажировку EPAM в Испании (1 из 8), CodeBattle (ITPU | EHU), олимпиада ITPU, AI-хакатон NewUU, Alif Academy, PROWEB Flutter, CityMove (Pizza&Pitch), волонтёрство ICTWeek и EPAM E-kids.

## 5. Механики и варианты для сравнения

Переключаются в панели «Пилот» в углу экрана и через URL (`?explore=1&finale=b`).

| Вариант | Что происходит |
|---|---|
| Линейный | Только скролл-маршрут, в конце финал и контакты |
| Линейный + свободный | После финала кнопка «Осмотреть доску»: таскать, зумить, клик по карточке — камера подлетает |
| Финал A | Камера возвращается в центр, карточка с силуэтом переворачивается — под ней фото, сверху бьёт штамп «ДЕЛО РАСКРЫТО» |
| Финал B | Отдельная папка «дело раскрыто» в углу доски, все нити сходятся к ней |

Всегда доступны:
- «Пропустить расследование» — HTML-досье с полным CV (оно же индексируется поисковиками) и скачивание PDF;
- RU/EN;
- звук машинки (по умолчанию выключен);
- фонарик за курсором (на телефоне — за пальцем), пыль в луче лампы, плёночное зерно и виньетка.

## 6. Визуальная система

| Токен | Цвет | Роль |
|---|---|---|
| Ночь | `#0A0806` | Тени, фон за доской |
| Лампа | `#FFB46A` | Тёплый ключевой свет, блики |
| Манила | `#C9A66B` | Папки, ярлыки, интерфейс досье |
| Бумага | `#E8DCC0` | Карточки, листы |
| Чернила | `#1C1A17` | Текст машинки |
| Нити | `#A3161A` / `#23477A` / `#3E6B3A` | Работа / учёба / хобби |

Шрифты, все с кириллицей:
- **IBM Plex Mono** — машинка: досье, субтитры, интерфейс;
- **Playfair Display** — газетные заголовки;
- **Old Standard TT** — газетный текст;
- **Caveat** — рукописные пометки;
- **Oswald** — штампы.

Интерфейс почти невидим: ярлык дела слева сверху, язык/звук/пропуск справа сверху, субтитры снизу. Прогресс — тонкая красная нить с булавками-остановками по правому краю.

## 7. Архитектура

```
src/
  content/      типизированные данные: улики, нити, остановки, профиль (RU/EN)
  experience/   3D: доска, карточки, нити, свет, пыль, эффекты
    painters/   рисование текстур карточек на canvas по типу улики
    camera/     маршрут по скроллу, свободная камера, кадрирование под экран
  ui/           HUD, досье, панель пилота
  audio/        синтез звука машинки (WebAudio, без файлов)
tools/blender/  скрипт сборки сцены из src/content
```

Сайт собирается в статику (`output: export`) и раздаётся nginx с твоего VPS.
